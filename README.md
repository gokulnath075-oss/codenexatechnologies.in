## 🚀 Live Preview & Running Locally

### Option A: One-Click Quick Launch
Double-click `launch-preview.bat` in the project root. It will start a local HTTP server and automatically open the website in your default browser at `http://localhost:8080`.

### Option B: Terminal / Command Prompt
```bash
# In the project directory:
python -m http.server 8080
```
Then open `http://localhost:8080` in Chrome, Edge, or Safari.

### Option C: Direct Browser Open
You can also directly double-click `index.html` to open it in any modern browser.
